# StarLight Workers

基于 Cloudflare Workers + D1 的社区系统。包含文章、评论、私信、工单、举报、OJ、比赛、队伍、以及多个小游戏模块。

## 本地开发

```bash
npm install
npx wrangler dev
```

## 部署

```bash
npm run deploy
```

> 如需生成 D1 绑定类型：`npx wrangler types`

## 环境变量（Secrets / Vars）

| 变量 | 必需 | 说明 |
|------|------|------|
| `ADMIN_PASSWORD` | 首次初始化时 | 创建初始管理员（`id=1, username=lin114514`）使用的密码。**不设置则管理员以禁用态（`use=0`）创建，无法登录**，需配置后重新初始化或手动在数据库中激活。 |

通过 `npx wrangler secret put ADMIN_PASSWORD` 或 `wrangler.jsonc` 的 `vars` 配置。

> ⚠️ 安全说明：本项目已移除内置的默认管理员密码。任何已有部署若仍在用旧版内置默认口令，请务必立即通过「个人设置 → 修改密码」更换，并升级到本版本以禁用内置口令引导。

## 目录结构

- `src/index.ts` — Worker 入口
- `src/router.ts` — 页面路由
- `src/handlers/` — `/api/*` 逻辑处理
- `src/routes/` — 页面渲染
- `src/db/` — 表结构与迁移
- `src/utils/` — 认证、权限、安全等工具

## 空间站搜刮行动

登录后访问 `/salvage`，进入单人空间站地图搜刮容器、战胜人机并撤离。地图扩大为 92×68，包含生活区、管理区、研发区、机组区、核心区、工程区、医疗隔离区、生态温室、观测穹顶和外环机库；舱段由不规则多边形空间与连接廊道组成，核心区高级收藏品概率更高，撤离点生成在地图边缘。主画面只展示玩家附近视野，右上角小地图显示全站布局。玩家按住 WASD 连续移动，也可点击地面行走；人机会巡逻、追击和攻击，头顶显示血条；玩家受伤时头顶显示血条与伤害值。靠近目标至曼哈顿距离 1.5 以内时，交互操作会实时更新；按 `T` 攻击（多目标时优先当前血量最高者）、按 `F` 搜索容器或拾取地面物资、按 `E` 自动交互。按 `L` 暂停 / 继续，暂停时移动、人机、回血和技能计时停止。局内搜索到的武器、护甲可直接装备，星晶可用于现场充能；背包物品可逐件丢弃，掉落物会显示在地图上并能再次拾取。移动、战斗、搜索与治疗在客户端即时运行；成功撤离或阵亡时仅提交一次本局记录。对局中隐藏仓库、制造商等局外界面。

背包与仓库均以二维格子展示，并按固定朝向自动排布、验证真实形状而非只比较总格数：1 级为 4×4 加 1×2 扩展格，2～6 级分别为 4×6、5×6、6×6、6×7、6×8。每级背包有三种负重规格：低为原始容量，中容量约增加 25%，高容量增加 50%；工程师另有独立 3×3 储物网格。物品按实际尺寸占格，例如磁约束核心为 3×3、星辉王冠为 1×1；图标底色表示物品等级（1 白、2 绿、3 蓝、4 紫、5 金、6 红），名称与说明保持统一文字颜色。自动拾取默认关闭；开启后，背包满时按每格价值比较，只会用更高价值搜刮物替换低价值背包物品，替换物会留在地面。局外可在仓库右侧查看物品详情并多选出售；制造商分类可折叠。局外配装显示背包、武器和护甲的总价值。制造配方会显示材料拥有数 / 缺少数，缺少材料可按原价的 1.1 倍补购。成功撤离的物品进入仓库，护甲磨损会折价；售出充能武器前需卸载完整星晶。武器含脉冲、磁轨和散射分支；制造商可并行排产，护甲可维修但每次维修都会降低耐久上限。混乱区装备价值门槛更高，敌人与掉落物资更强；阵亡会丢失本局带入及搜刮的全部物品。

每局出发前可选择职业：医生自动恢复 1 HP/s，按 `P` 后恢复 10 HP/s 持续 5 秒；工兵基础移速 +50%，技能使移速 +200% 持续 10 秒；工程师获得额外 3×3 储物格，技能冻结附近人机 3 秒；士兵生命值 +10%、受到伤害减免 5%，技能使移速 +100% 并提高攻击伤害 20%，持续 10 秒。所有职业技能冷却均为 40 秒。

相关 D1 表与索引会随数据库 schema 初始化自动创建。

## 即时通知

经典 UI 的左侧导航按 Overview、Community、Build、Apps、Account 和 Administration 分组。登录后的 HTML 页面会每 2 秒检查一次即时通知并在页面内弹窗；浏览器提及通知轮询间隔为 3 秒。仅 UID 1 的已登录会话可以发送即时通知：`GET /api/noti?u=<接收UID>&t=<标题>&c=<内容>`。通知轮询接口为登录态 `GET /api/noti/poll?after=<通知ID>`；浏览器使用用户本地游标避免重复显示。
